# BLOCKDASH v2.1 통합 개발 소스

> 확정된 BLOCKDASH 기획에 맞춰 제작한 **3D 브라우저 게임 통합 개발본**입니다. 원본 BLOCKDASH 베타 v1.1의 파일을 별도 보관한 상태에서, 게임 규칙과 화면을 v2.1 사양으로 개편했습니다. **실기기 검증과 공개 서버 배포까지 완료된 정식 출시본은 아닙니다.**

## 포함된 기능

- **4개 모드:** 연습, AI 대전, 온라인 개인전(FFA), 온라인 팀전(2v2/3v3/4v4). 파쿠르 없음.
- **경기 규칙:** 6분, 체력 100, 리스폰 5초, 부활 후 3초 무적, 피격 5초 뒤 체력 재생, 처치 100점/어시스트 25점.
- **20종의 가상 무기:** AR/SMG/SR/SG/HG 5분류. 기획에서 확정한 피해량·발사 간격·탄창·재장전·반동·등급을 `shared/rules.js`에 일괄 정의했습니다. 화면에 보이는 장비는 단순 기하학 형태의 저폴리 소품이며, 현실 장비의 작동법과는 관련 없습니다.
- **2개 로우폴리 맵:** BLOCK YARD 100×100, SKY GRID 90×90; 캐릭터/장비 시각화, 사격 효과, 리스폰 효과.
- **AI:** 쉬움/보통/어려움, 최대 7개 봇, 간단한 엄폐/추적/거리 관리.
- **상점:** 경기에서 얻는 가상 화폐 BDC만 이용. 1회 700, 10회 6000, 등급 확률 70/25/4.5/0.5%, 중복 환급 350. 현금 결제·충전·현금화 기능은 없습니다.
- **시네마틱:** 3D 금속 상자 개봉, 조명과 색상 변화, 회전하는 저폴리 보상, 소리, 10개 결과 공개, 건너뛰기.
- **UI:** 기존 컨셉의 차콜·건메탈·주황 포인트, 자연스러운 한국어 화면 문구, 경기 HUD, 보유 무기, 설정, 결과, 연습 기록.
- **조작:** PC 마우스/키보드, 아이패드 가상 버튼. 가상 버튼 드래그와 크기 편집은 브라우저별 저장.
- **서버:** Node.js HTTP + WebSocket 실시간 방 운영/경기 판정, 계정 비밀번호의 scrypt 해시 저장, 서버 측 BDC 및 계정 무기 소유권 관리.

## 빠른 로컬 실행

Node.js **20 이상**과 Python 3이 있으면 편리합니다.

```bash
# 터미널 A — 계정·실시간 게임 서버
node server/index.js

# 터미널 B — 정적 웹 게임(예: 로컬 테스트)
python -m http.server 8000
```

PC에서 `http://localhost:8000`을 엽니다. 연습과 **게스트 AI 대전은 게임 서버 없이도** 플레이할 수 있습니다. 로그인/온라인 기능은 게임 메뉴의 계정 서버 주소에 `http://localhost:3001`, 온라인 서버 주소에 `ws://localhost:3001/ws`를 입력해야 합니다. 온라인 FFA는 최소 2명, 팀전은 2v2 이상 참가해야 시작합니다. **아이패드처럼 다른 기기에서 접속할 경우**, 호스트 PC의 실제 네트워크 주소와 브라우저 보안 조건에 맞는 HTTPS/WSS 연결 설정이 필요합니다.

> 로컬 브라우저는 Three.js v0.180 모듈을 jsDelivr CDN에서 불러옵니다. 따라서 최초 실행 시 인터넷 연결이 필요합니다. 오프라인 단독 실행을 위한 라이브러리 내장은 아직 하지 않았습니다.

## 테스트

```bash
npm run check
npm test
```

`npm run check`는 JS 구문을 확인하고, `npm test`는 게임 규칙·프로필·서버 연동·HTML UI 요소·배포 구성에 대한 자동 테스트를 실행합니다. **자동 테스트 통과가 실제 브라우저 3D 렌더링, 아이패드 실기기 UX, 외부 공개 서버 보안/성능 검증을 의미하지는 않습니다.** 결과는 `TEST_REPORT.md` 참고.

## GitHub Pages와 공개 온라인 서버

`.github/workflows/deploy.yml`은 저장소 `main`에 파일을 업로드했을 때 테스트 후 `index.html`, `src/`, `shared/`를 **정적 웹사이트**로 배포합니다. `server/`는 GitHub Pages에서 실행되지 않습니다. 공개 온라인 게임과 계정 저장 기능에는 **별도의 지속 실행 Node.js 서버**와 HTTPS/WSS 엔드포인트가 필요합니다.

프로덕션 환경에서는 다음을 권장합니다.

```bash
PORT=3001 ALLOWED_ORIGINS=https://jihuncha98.github.io BLOCKDASH_DATA_FILE=./server/data/profiles.json node server/index.js
```

- `ALLOWED_ORIGINS`는 브라우저 Origin의 정확한 값이어야 합니다. 실제 사이트 주소가 다르면 해당 주소를 지정하세요.
- `server/data/`는 `.gitignore` 대상이며 **비밀번호 해시와 유저 프로필을 담으므로 절대로 GitHub에 커밋하지 마세요.**
- 공개 서비스 전 HTTPS/WSS 프록시, 방화벽, 요청 제한, 세션 처리, 데이터 백업/복구, 악의적 클라이언트 검증, 다중 사용자 성능에 대한 별도 보안 점검이 필요합니다.
- 계정 토큰은 서버 메모리에 저장되므로 서버 재시작 후 로그인이 다시 필요할 수 있습니다.
- 기존 beta 저장소를 교체한다면 원본을 ZIP/태그로 **반드시 백업**하고 GitHub Actions 결과를 확인하세요.

## PC 조작

- `WASD`/방향키: 이동 · `Shift`: 달리기 · `Ctrl`: 앉기 · `Space`: 점프 · `C`: 슬라이드
- 왼쪽 마우스: 사격 · 오른쪽: 조준 · `R`: 재장전 · `1`/`2`: 주무기/권총 · `Q`: 무기 교체 · `V`: 저격 스코프 배율
- 사망 후 5초 대기 중 `Z`/`X`: 보유 무기에서 주무기/권총 교체 · `Esc`: 일시정지 · `Tab`: 순위
- 아이패드: 터치 조이스틱·조준 영역·행동 버튼, 설정에서 버튼 위치와 크기 조절.

## 프로젝트 구조

| 경로 | 역할 |
|---|---|
| `index.html` | 게임 로비·HUD·모달·시네마틱 HTML |
| `src/app.js` | 게임 화면 및 사용자 상태를 연결하는 프런트엔드 진입점 |
| `src/world.js` | Three.js 3D 맵·캐릭터·저폴리 장비·전투 시각화 |
| `src/controls.js` | PC/터치 조작·버튼 편집 |
| `src/ai.js` | AI 모드 |
| `src/cinematic.js` | 보상 개봉 애니메이션 |
| `src/profile.js` | 게스트·계정 프로필과 가상 BDC |
| `src/network.js` | 온라인 WebSocket 클라이언트 |
| `shared/rules.js` | 확정 게임 수치·피해·이동·무기·보상 공통 규칙 |
| `server/` | 온라인 방·점수 검증·인증·계정·데이터 저장 |
| `tests/` | 자동 테스트 |
| `.github/workflows/deploy.yml` | Pages 정적 클라이언트 배포 |

## 현재 제한사항

이 통합본의 핵심 로직은 자동 검증했지만, **PC·아이패드에서의 전체 경기 실플레이와 외부 공용 서버 배포는 아직 직접 검증하지 않았습니다.** 3D 소품과 애니메이션은 개발용 프로시저럴 모델이며, 제작된 최종 고품질 모델/녹음 음원 에셋이 아닙니다. 렌더링·터치 입력·지연·서버 부하 테스트 결과에 따라 보완이 필요할 수 있습니다.
